Apa itu PPLG?

Pengembangan Perangkat Lunak dan Gim (PPLG) adalah jurusan yang mempelajari cara pembuatan, pemeliharaan, dan pengembangan perangkat lunak (software) serta gim. Di jurusan ini, siswa dibekali kemampuan logika pemrograman, desain UI/UX, manajemen basis data, hingga pengujian aplikasi.

Kompetensi yang Dipelajari

  • Pemrograman Web (HTML, CSS, JavaScript)
  • Pemrograman Berbasis Objek & Bahasa Lanjutan (Python, C++)
  • Basis Data (Database) & SQL
  • Pengembangan Aplikasi Mobile (Android/iOS)
  • Pengembangan Gim (Game Development)

Prospek Kerja Graduates PPLG

Mobile App Developer

Software Engineer

Kegiatan Siswa PPLG

Dipublikasikan: 28 September 2026

Siswa PPLG tidak hanya belajar teori di kelas, tetapi juga aktif dalam pembuatan proyek nyata (*Project-Based Learning*). Minggu ini, siswa kelas X PPLG sedang menyelesaikan tantangan pembuatan landing page responsif dan prototipe gim 2D sederhana. Kegiatan ini bertujuan melatih pemecahan masalah (problem solving) serta kerja sama tim seperti di lingkungan kerja profesional.

Informasi Tambahan

Belajar HTML, CSS, dan logika pemrograman merupakan langkah awal terpenting dalam dunia pengembangan web dan perangkat lunak.
